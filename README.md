# Creality Helper Script

## About


    This script intended for use on Creality **K1 Series** and **Ender-3 V3 Series** printers allows to add more features.

    Must-Read Before Use: Minimalist Guide to Leveling Ender-3/K1 Series (5 Steps to Solve the “Poor Bed Adhesion” Issue)

(Note: Leveling is a prerequisite for optimizing prints with scripts; improper leveling may cause model warping or detachment.)

###Step 1: Place A4 Paper

Place an A4 paper between the print bed and the nozzle (heat the nozzle to 180°C).

###Step 2: Adjust Screws

Use the leveling screws to adjust the bed height until “pulling the A4 paper has slight resistance” (like the force of “gliding over skin”).

###Step 3: Test 4 Corners + center

Repeat adjusting the bed’s 4 corners and center to ensure “consistent resistance at each point.”

###Step 4: Print Test Model

Print a “10mm cube” (slice with Cura, layer height 0.2mm) and check if the “bottom surface is flat.”

###Step 5: Fine-Tune (If Warping Occurs)

If the bottom surface warps, increase the “bed temperature” from 50°C to 60°C (for PLA material).
